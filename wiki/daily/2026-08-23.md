# 2026-08-23

## Repo atlas

Built `scripts/repoAtlas.ts` + `repoAtlas.template.html`, generating
`docs/prototypes/repo-atlas.html` - one sortable page covering every live
branch, merged-and-deleted stream, worktree, and stray workspace dir. Merged
streams are reconstructed from merge-commit second parents, so branches that
were deleted after merging still show their commit count, churn, and dates.
Sort by last updated, commits, ahead/behind dev, churn, files, or span; filter
chips per kind. Re-run with `bun run scripts/repoAtlas.ts`.

Two Windows escaping gotchas cost the first two runs (both now in the script's
comments): `|` as a git `--format` separator gets swallowed as a shell pipe
(use `%x1f`), and `^` in a revision is cmd.exe's escape character unless the
whole rev is quoted - `git rev-list "$h^1..$h^2"`. The second one silently
returned zero merged streams rather than erroring.
